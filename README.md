# CyberRange Academy

CyberRange Academy is a self-contained cybersecurity training game that runs in the browser. It works offline and saves progress in this browser's localStorage. All labs are simulated against fictional targets.

From Home / Profile you can export that progress to a JSON file and import it later, including on another browser or an installed copy, so a backup survives clearing browser data.

The Leaderboard compares that saved XP with fictional classmates. It stays on this device and does not upload scores.

Daily is five questions from the existing quiz, fixed for the UTC date. Clearing them once that day raises a streak. The date and streak are part of the progress backup. Older backup files that have no streak still import.

**Live site:** https://ella1536von-ops.github.io/ellathehackervon/

## Add it to an Android home screen

1. Open the live site in Chrome.
2. Tap the menu (three dots).
3. Tap **Install app** or **Add to Home screen**.
4. Confirm. CyberRange opens full screen, like an app, and stays available offline after the first visit.

On iPhone, open the site in Safari, tap Share, then **Add to Home Screen**.
